# Project 5 - Pokédex (API + Animation)

**Live site:** https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/

## About
A Pokédex web page that pulls data from the [PokéAPI](https://pokeapi.co/).

- **API:** PokéAPI (loads 12 random Pokémon, or search by name/number)
- **Animation:** [anime.js](https://animejs.com/) (title bounce, cards sliding in, click a card to spin its picture)
- **CSS:** Flexbox (header and search bar) and CSS Grid (card layout), plus hover and active states
